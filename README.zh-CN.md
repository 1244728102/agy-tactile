## ✨ Overview & Highlights

**AGY Tactile Engine · Codex 级物理阻尼手感引擎 (`agy-tactile`)** — 把 Antigravity 的点击手感调成 Codex 那种：按下有轻微回弹、过渡跟手、开关带一点弹性，不再硬切。纯样式注入，不动安装目录。

## 🚀 Quick Install

**Windows PowerShell**:
```powershell
git clone https://github.com/1244728102/agy-tactile.git "$env:USERPROFILE\.gemini\config\plugins\agy-tactile"
```

**macOS / Linux**:
```bash
git clone https://github.com/1244728102/agy-tactile.git "$HOME/.gemini/config/plugins/agy-tactile"
```

**Or hand the install to your AI agent**:
> Install and configure `agy-tactile` following https://github.com/1244728102/agy-tactile/blob/main/INSTALL.md
